Concept

What is Full Stack Development?

Full stack development refers to the practice of building both the front end (what users see and interact with) and the back end (the server, database, and application logic) of a web application. A full stack developer is comfortable working across every layer of a system.

The term "stack" describes the collection of technologies layered together to form a complete product. Each layer has a specific responsibility and communicates with the layers around it.

UI
Presentation Layer

HTML, CSS, JavaScript — what the user sees

FE
Client-Side Logic

React / Vue / Vanilla JS — dynamic behaviour

API
Application / Business Logic

Node.js, Python, PHP — processes requests

DB
Data Layer

SQL / NoSQL databases — stores persistent data

INF
Infrastructure

Servers, cloud hosting, CDN, DNS

Front End vs. Back End vs. Full Stack

Front-end developers specialise in the browser — building layouts, styling, and interactivity. Back-end developers work on servers, APIs, databases, and security. A full stack developer bridges both, allowing them to architect complete features from database schema to pixel-perfect UI — making them especially valuable on small teams or in fast-moving startups.

02

Structure

HTML — HyperText Markup Language

HTML is the skeleton of every web page. It defines the semantic structure of content — headings, paragraphs, lists, links, tables, forms — using a system of tags and attributes. Browsers parse HTML into a tree structure called the Document Object Model (DOM), which other technologies like CSS and JavaScript then interact with.

Why Semantic HTML matters

Semantic elements like <header>, <nav>, <main>, <article>, <footer> communicate meaning, not just appearance. This improves accessibility (screen readers understand the page hierarchy), SEO (search engines index content better), and maintainability.

HTML5 Document <!-- A minimal, semantically correct HTML5 page --> <!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>My Page</title> </head> <body> <header> <nav><a href="/">Home</a></nav> </header> <main> <article> <h1>Hello, World</h1> <p>This is a paragraph.</p> </article> </main> <footer>© 2025</footer> </body> </html>

The key attributes on line 1–6 are critical: lang="en" declares the language for accessibility tools, charset="UTF-8" ensures correct character encoding, and the viewport meta tag enables responsive behaviour on mobile devices.

03

Presentation

CSS — Cascading Style Sheets

CSS controls the visual presentation of HTML — colour, typography, spacing, layout, animation and responsive design. Styles "cascade" from general rules down to specific ones, with specificity and inheritance determining which rule wins when multiple rules target the same element.

The Box Model

Every HTML element is rendered as a rectangular box. The CSS box model consists of four areas from inside out: content (the actual content), padding (space inside the border), border (the element boundary), and margin (space outside the border). Setting box-sizing: border-box makes width/height include padding and border, which is the modern standard.

CSS3 Examples /* ── Selectors & Properties ── */ .card { background: #ffffff; border-radius: 8px; box-shadow: 0 4px 16px rgba(0,0,0,0.08); padding: 1.5rem; transition: transform 0.3s ease; } .card:hover { transform: translateY(-4px); } /* ── Flexbox layout ── */ .nav { display: flex; justify-content: space-between; align-items: center; gap: 1rem; } /* ── CSS Grid ── */ .grid { display: grid; grid-template-columns: repeat(auto-fit, minmax(200px, 1fr)); gap: 1.5rem; } /* ── Media query (responsive) ── */ @media (max-width: 768px) { .grid { grid-template-columns: 1fr; } } /* ── CSS Custom Properties (variables) ── */ :root { --primary: #c1440e; --font-heading: 'Playfair Display', serif; } h1 { font-family: var(--font-heading); color: var(--primary); }

Framework

Bootstrap 5 Framework

Bootstrap is the world's most popular open-source CSS framework. It provides a 12-column responsive grid system, a comprehensive library of pre-built UI components (buttons, cards, modals, navbars, forms, alerts), and utility classes — all designed to accelerate development and ensure consistency across browsers.

Why use a framework?

Writing CSS from scratch for every project is time-consuming and error-prone. Bootstrap solves common layout and component problems with battle-tested, accessible, cross-browser-compatible code. Developers include it via a single <link> tag (CDN) or npm package, then build with its classes without writing raw CSS for standard components.

Behaviour

JavaScript — Dynamic Behaviour

JavaScript is the programming language of the web. While HTML provides structure and CSS provides style, JavaScript adds behaviour — responding to user events, manipulating the DOM, fetching data from APIs, and enabling fully interactive experiences without page reloads.

How JavaScript works in the browser

JavaScript is executed by the browser's JS engine (e.g. V8 in Chrome). Scripts can target HTML elements via the DOM API (document.querySelector), attach event listeners (addEventListener), and modify content, attributes, or styles dynamically. Modern JS (ES6+) introduces classes, arrow functions, template literals, destructuring, modules, and async/await for cleaner, more expressive code.

JavaScript ES6+ // ── DOM manipulation ── const btn = document.querySelector('#myBtn'); btn.addEventListener('click', () => { document.querySelector('#output').textContent = 'Clicked!'; }); // ── Arrays & functional methods ── const todos = ['Learn HTML', 'Study CSS', 'Build a project']; const done = todos.filter(t => t.startsWith('Learn')); // ── Async / Fetch API ── async function getUser(id) { const res = await fetch(`https://api.example.com/users/${id}`); const data = await res.json(); return data; } // ── Classes (OOP) ── class TodoList { constructor() { this.items = []; } add(text) { this.items.push({ text, done: false }); } toggle(i) { this.items[i].done = !this.items[i].done; } }
